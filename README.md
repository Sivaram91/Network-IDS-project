# Network Intrusion Detection System with Full scale ML and TinyML

A dual-layer security system using **Machine Learning** (Raspberry Pi) and **TinyML** (STM32) for real-time network intrusion detection.

## Quick Overview

- **Raspberry Pi 4**: Full-scale ML-based IDS for comprehensive traffic analysis
- **STM32H755**: TinyML fuzzing detection at the network edge
- **Attacks Detected**: Port scanning, DoS, data exfiltration, malformed packets
- **Use Cases**: Automotive, IoT, and embedded network security
